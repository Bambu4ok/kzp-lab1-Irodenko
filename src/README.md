# KZP Lab 2 — Комунальні показники (Варіант 9)

## Опис проєкту
Проєкт реалізує обробку показників комунальних лічильників з використанням об'єктно-орієнтованих принципів Java 21 (класи-сутності, record, інкапсуляція).

## Архітектура
- `UtilityReading`: Клас-сутність із незмінним станом (`private final`), валідацією інваріантів у конструкторі та статичним фабричним методом `fromCsv`.
- `UtilitySummary`: Record для збереження підсумкових агрегованих показників.
- `Main`: Головний клас обробки даних, що зберігає сумісність звіту з ЛР1.

## Запуск та тестування
- Запуск тестів: `.\mvnw.cmd test`
- Запуск програми: `.\mvnw.cmd compile exec:java "-Dexec.mainClass=ua.lpnu.kzp.Main"`
